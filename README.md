# OpenLib catalog

One Markdown file per vetted library under `catalog/`. Each file starts with a YAML front-matter block.

Fields: title, slug, permalink, date, publication_status, upstream_package, hosturl, docsurl and an optional repo_url.

The team's delivery workspaces live under `workspaces/<name>/` in this same repository; each workspace README names the catalogue entry it implements and declares its availability.
